Windows用の画面キャプチャ

範囲の切り取り・固定、OCR、ライブプレビュー。

Microsoft Storeで入手

選択した範囲を最前面に表示します。

切り取った画像の文字を認識し、テキストとしてコピーできます。

選択した範囲の変化を、別ウィンドウにリアルタイムで表示します。

基本の使い方

範囲を切り取る
Ctrl + Shift + 5
文字を読み取る（OCR）
Ctrl + Shift + 4
ライブプレビュー
Ctrl + Shift + 6
画像をコピー / 保存
Ctrl + C / Ctrl + S

切り取った画面を右クリックすると、拡大縮小、不透明度、コピー、保存などを操作できます。ショートカットは初期設定です。

画面を切り取り、固定する
  1. Kiritoriを起動します。
  2. Ctrl + Shift + 5を押し、切り取りたい範囲をマウスでドラッグします。
  3. 選択した範囲が別ウィンドウに表示され、最前面に固定されます。

最前面固定は、切り取った画面の右クリックメニュー、またはCtrl + Aで切り替えられます。

画像の文字をコピーする（OCR）

Ctrl + Shift + 4を押し、文字を読み取りたい範囲をドラッグで選択すると、テキストを抽出できます。

画像としてコピーする場合は、切り取ったウィンドウでCtrl + Cを押します。OCRによる文字の抽出とは異なります。

変化する画面をライブプレビューで表示する

Ctrl + Shift + 6を押し、表示したい範囲をドラッグで選択します。選択範囲の変化が、別ウィンドウにリアルタイムで表示されます。

キャプチャ方式のAutoモードはGPUを優先し、利用できない環境や複数モニターにまたがる範囲ではGDI互換モードへ切り替えます。

大きさ・不透明度・表示位置を調整する
  • 右クリックメニューから拡大率や不透明度を選べます。
  • ウィンドウの端をドラッグしてサイズを変更できます。Shiftを押しながら変更すると縦横比を維持します。
  • Ctrl + 0で等倍、Ctrl + + / Ctrl + -で拡大・縮小できます。
  • 矢印キーで位置を微調整できます。Shiftを押しながら矢印キーを押すと、より大きく移動します。
コピー・保存・印刷・ペイントで編集する
  • Ctrl + Cで画像をクリップボードにコピーします。
  • Ctrl + Sで画像を保存、Ctrl + Oで画像ファイルを開きます。
  • Ctrl + Pで印刷できます。
  • 右クリックメニューの「Edit in Paint」からペイントで編集できます。保存してペイントを閉じると、編集内容がKiritoriに反映されます。PNGの透明部分は失われる場合があります。
ウィンドウを閉じる・履歴を開く・アプリを終了する

切り取ったウィンドウはEsc / Ctrl + W、または右上にマウスを重ねると表示される×ボタンで閉じられます。Ctrl + Hで最小化できます。

Kiritoriはタスクトレイに常駐します。トレイアイコンの右クリックメニューからキャプチャや履歴を開けます。アプリを終了する場合は「Exit Kiritori」を選びます。

よくある質問

どこから入手できますか？

Microsoft Storeから入手できます。

SmartScreenが表示される場合は？

署名がない配布ファイルや配布直後のファイルでは、警告が表示されることがあります。入手元と発行元を確認してください。Microsoft Storeでの配布も利用できます。

対応するWindowsのバージョンは？

Windows 10 バージョン1809以降、Windows 11（x64）に対応しています。GitHub配布版の実行には.NET Framework 4.8が必要です。

画面や読み取った文字は外部に送信されますか？

画面キャプチャや文字認識は端末内で処理されます。個人情報の収集やトラッキングは行いません。詳しくはプライバシーポリシーをご覧ください。

不具合の報告や最新の変更内容はどこで確認できますか？

不具合の報告はGitHub Issuesへ。更新内容はリリース情報で確認できます。
