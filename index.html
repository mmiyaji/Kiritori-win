Version 1.7.2

より速く、安定したライブプレビュー

Windows Graphics Capture と Direct3D 11 を使うGPUキャプチャを追加。AutoモードはGPUを優先し、必要に応じてGDIへ切り替えます。

Live Preview now prefers GPU capture, with automatic GDI fallback for compatibility.

主な改善 / Highlights
  • フレーム制御、更新領域、拡縮処理を最適化
  • CPU使用率を削減し、フレームレートを改善
  • 設定とメニューからキャプチャ方式を選択可能
  • OCR、GIF、FFmpeg周辺の安定性を改善
Windows 10 / 11 対応。詳細は リリースノート と プライバシーポリシー をご覧ください。
